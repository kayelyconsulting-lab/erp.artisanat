KAYELY GESTION PRO — Console sociétés

Configurer la console

Dans le Gestionnaire de fichiers LWS, ouvrez le dossier des données (donnees à côté de index.php, ou kgpro-donnees) et le fichier CODE-CONSOLE.txt : il contient le code d'installation. Choisissez ensuite le mot de passe de la console (10 caractères minimum).

Connexion à la console

Réservée à Kayely Group : création et gestion des sociétés clientes.

Mot de passe oublié ?
  1. Dans LWS Panel, ouvrez le Gestionnaire de fichiers, puis le dossier des données (donnees à côté de index.php, ou kgpro-donnees).
  2. Cliquez sur « + Fichier » et créez un fichier nommé REINITIALISER-CONSOLE (vide).
  3. Rechargez cette page : la console repasse en configuration. Le nouveau code d'installation est dans CODE-CONSOLE.txt, dans le même dossier.

Clés d'activation

L'extension PHP sodium n'est pas activée. Dans LWS Panel : Configuration php → cochez sodium, puis rechargez cette page.

Pour émettre des clés, la console a besoin d'une clé de signature. Elle est créée une seule fois et rangée dans le dossier des données (kgpro-donnees/licence-signature.key), hors du site public. Pensez à la sauvegarder avec le reste du dossier : sans elle, impossible d'émettre de nouvelles clés reconnues par les installations existantes.

La clé est liée au nom de la structure et à la date d'échéance : le client saisit ce même nom avec la clé dans l'écran d'activation (il est prérempli pour les sociétés hébergées ici).
